# SafeFlow - Landing Page

> Plataforma tecnológica avanzada para el monitoreo y control en tiempo real de la cadena de frío en almacenamiento y transporte logístico. Desarrollado por **Cryologic**.

---

## Demo 
Puedes visualizar la landing page en funcionamiento a través del siguiente enlace:
🔗 **[Ver Demo](https://upc-pre-202610-1asi0730-20177-cryologic.github.io/safeflow-website/)** 

---

## Descripción del Proyecto
**SafeFlow** es una landing page corporativa diseñada con un enfoque moderno, limpio y profesional, orientada a empresas del sector logístico, farmacéutico y alimentario. El sitio web tiene como objetivo presentar una solución de vanguardia en telemetría y monitoreo térmico, destacando el valor de asegurar las condiciones óptimas de productos sensibles a la temperatura durante toda la cadena de suministro.

### Secciones Principales Incluidas:
* **Navbar (Navegación):** Menú limpio con accesos directos a Plataforma, Características, ¿Cómo funciona?, Planes, Nosotros, Sectores y Contacto.
* **Selector de Idioma:** Botón funcional e interactivo en la cabecera para alternar la interfaz entre Español (ES) e Inglés (EN).
* **Sección Hero:** Impactante imagen de fondo de un almacén frigorífico industrial con tipografía superpuesta de alto contraste, propuesta de valor clara ("Control Total de tu Cadena de Frío") y un botón Call-To-Action (CTA) dinámico ("Ver Demo").

---

## Características Técnicas (Features)
* **Estructura Semántica Avanzada:** Uso correcto de etiquetas HTML5 (`<header>`, `<nav>`, `<section>`, `<main>`) para mejorar el SEO y la accesibilidad.
* **Diseño Totalmente Responsivo:** Adaptabilidad fluida garantizada en dispositivos móviles, tablets y pantallas de escritorio mediante CSS Media Queries.
* **Layout Moderno:** Implementación de técnicas avanzadas de posicionamiento y distribución con Flexbox y CSS Grid.
* **Interactividad y Conmutación de Idioma:** JavaScript Vanilla implementado para manejar el cambio dinámico de textos (i18n local) entre Español e Inglés sin recargar la página, además de navegación suave (Smooth Scroll).
* **Optimización Visual:** Uso de superposiciones oscuras (*overlays*) mediante gradientes CSS para asegurar la perfecta legibilidad del texto sobre imágenes complejas de fondo.

---

## Tecnologías Utilizadas
* **HTML5:** Maquetación estructural, semántica y estructuración del contenido.
* **CSS3:** Estilos personalizados, arquitectura de diseño responsivo, variables nativas para la paleta de colores corporativa (Azul SafeFlow, Naranja Alerta, Blanco Pureza) y efectos de transición (hover).
* **JavaScript :** Lógica del lado del cliente para interactividad, animaciones de componentes y lógica del selector de idioma.
